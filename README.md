OID Segmentation Model
===

> Open Images Data - Segmentation Model Training Tool

**Project Summary:**

- [X] Downloads assets from Google's [Open Images Dataset](https://storage.googleapis.com/openimages/web/index.html)
- [X] Prepares assets for use with [YOLOv8](https://docs.ultralytics.com/)
- [X] Generates custom Segmentation Model
